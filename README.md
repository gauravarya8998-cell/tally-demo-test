#📘 Tally Demo Test

An interactive Tally with GST Practice Test built using **HTML, CSS, and JavaScript.
This web application is designed to help students and beginners strengthen their accounting
knowledge through a clean, responsive, and user-friendly quiz interface.

#📖 Overview

Tally Demo Test simulates a real online practice examination by presenting multiple-choice questions on Tally and GST concepts.
The application automatically evaluates user responses and provides instant performance analysis.
This project demonstrates fundamental front-end development skills while offering a practical learning tool for accounting students.

#✨ Features

✅ Interactive Multiple Choice Questions (MCQs)
🔀 Randomized Question Selection
⚡ Instant Result Evaluation
📊 Performance Summary
✅ Correct & Incorrect Answer Highlighting
📱 Responsive Design
🎨 Clean and Professional User Interface
🚀 Runs Completely in the Browser
❌ No External Libraries or Frameworks Required

#🛠️ Built With

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
